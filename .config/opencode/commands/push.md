# Push

Inspect `git status` and `git diff`, group related changes into clean commit(s) matching the repo's recent commit style, run obvious fast checks or linters if present, and push to the remote tracking branch. Stop and warn instead of committing or pushing if secrets, sensitive files, or failing checks show up.

!`git status --short && git log --oneline -5`
